
# Functional Requirements

Functional requirements describe the features and operations that the CampusConnect system must provide.

| ID | Requirement |
|---|---|
| FR-01 | Users can register and log in securely. |
| FR-02 | The system supports Student, Faculty and Admin roles. |
| FR-03 | Admins can manage user accounts and courses. |
| FR-04 | Faculty can create and manage assignments. |
| FR-05 | Students can view their enrolled courses. |
| FR-06 | Students can submit assignments online. |
| FR-07 | Faculty can review submissions and provide feedback. |
| FR-08 | Users can view course announcements. |
