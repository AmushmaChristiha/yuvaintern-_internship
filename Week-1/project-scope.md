
# CampusConnect - Project Scope

## 1. Project Description

CampusConnect is a web-based Student Course and Assignment Management System designed to simplify academic activities.

## 2. In-Scope Features

The initial version of the system will include:

- User login and authentication.
- Student, Faculty and Admin roles.
- Course management.
- Assignment creation and management.
- Online assignment submission.
- Submission status tracking.
- Faculty feedback.
- Course announcements.

## 3. Out-of-Scope Features

The following features are excluded from the initial version:

- Android and iOS mobile applications.
- Live video classes.
- Online payment integration.
- AI-based grading.
- Automated plagiarism detection.
- Third-party college ERP integration.

## 4. Target Users

- Students
- Faculty Members
- Administrators

## 5. Expected Benefits

- Centralised academic information.
- Easier assignment management.
- Reduced manual communication.
- Better tracking of student submissions.
- Improved coordination between students and faculty.

## 6. Conclusion

The defined scope provides a clear boundary for the CampusConnect project and helps ensure that development remains focused on the essential features of the initial release.
