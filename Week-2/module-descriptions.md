# CampusConnect - Module Descriptions

## 1. User and Authentication Module
Manages user accounts, login, logout and role-based access for students, faculty and administrators.

## 2. Student Module
Allows students to view enrolled courses, access assignments, submit their work and check feedback.

## 3. Faculty Module
Allows faculty members to manage courses, create assignments, review submissions and provide feedback.

## 4. Course Management Module
Maintains course details and manages the association between students, faculty and courses.

## 5. Assignment and Submission Module
Handles assignment creation, instructions, deadlines, file uploads and submission status.

## 6. Feedback Module
Stores faculty comments, marks and review information for student submissions.

## 7. Administration Module
Allows authorised administrators to manage users, roles and platform records.

## 8. Notification Module
Supports notifications about new assignments, upcoming deadlines and feedback availability.

## Conclusion
Each module has a specific responsibility. Together, these modules provide an organised system for managing academic activities through CampusConnect.
