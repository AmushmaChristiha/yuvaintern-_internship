# Week 2 - System Architecture Design & Mockup

## Project
CampusConnect - Student Course & Assignment Management System

## Objective
To design the high-level system architecture of CampusConnect and understand how its modules interact with each other.

## Work Completed
- Prepared the system overview.
- Designed the proposed three-tier architecture.
- Identified the major system modules and their responsibilities.
- Prepared a high-level system architecture diagram.
- Created a data-flow diagram.
- Identified the proposed technology stack.
- Documented module interactions and integration points.
- Discussed scalability, security and maintainability.

## Technology Stack
- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MongoDB
- Communication: REST API and HTTPS

## Deliverables
- System Architecture Design Document (.docx)
- High-Level Architecture Diagram
- Data-Flow Diagram
- Module Descriptions
